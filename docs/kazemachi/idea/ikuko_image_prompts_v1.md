| 1枚目（ベージュカーディガン） | 雰囲気◎、WINSの空気感が出ている、笑顔が自然 | テキスト「WINS后楽園1陵」が入ってしまっている |

## ■ イクコ固定スペック（全プロンプト共通）

### キャラクター基本情報
```

### 顔面スペック（全プロンプトに適用）
```
【顔面スペック】
輪郭: 丸顔。ほっぺがやや丸みを帯びている
目: 細め一重寄り。笑うとほとんど閉じる。目尻にシワ

瞳: 小（細目で一重）

口元: 口角がしっかり上がった笑顔。唇はやや厚め
肌: 暖色系。ほうれい線・目尻のシワ・口元の小ジワが生活感を作る
体格: ふくよかで小柄。肩幅は狭め。丸みがある
```

### 服装のバリエーション（プロンプトごとに指定）
```
【服装A】ベージュ〜グレージュのカーディガン（基本形・最も自然）

【服装D】春秋：花柄のポロシャツ＋カーディガン羽織り

## ■ 共通スタイル指定（全プロンプトに冒頭付与）

```
【必須スタイル指定】
- 日常アニメ系。スキップとローファー〜ふつうの軽音部のラインのテイスト
- 線: 手描き感のある温かい線、少しはみ出し、不完全でも味がある
- 色調: 低彩度、フラット、ウォーターカラーウォッシュ。競馬場の午後の暖かい光
- 背景: 控えめ（最低限の環境描写でキャラの空気感を邪魔しない）
- 構図: 上半身〜バストアップ（一部は全身・腰上も可）
- 記号アイテムは手元〜胸元に必ず入れる
- 文字・テキスト・ロゴは一切入れない（重要）
- 年齢を正確に出す（67歳のシワ・白髪を誤魔化さない。でも怖くない、温かい）
- リアル寄りだがイラスト的なタッチ（実写ではない）
```

### 参照画像でタッチを揃える場合（参照添付時はこれを先頭に）

```
【絵柄統一・最重要】
添付画像とまったく同じアートスタイルで描くこと。
同じ作家が同じ画材で描いたように見えること：
- 線：同じ太さ・同じ手描き感（少しはみ出す不完全さも同じに）
- 色：同じ彩度（低彩度）・同じ色温度・同じフラット塗り＋水彩のにじみ
- デフォルメ度合い・目鼻の記号化レベルも添付画像と同じ
- 光：競馬場の午後の柔らかい光
ただし【人物・ポーズ・構図・背景は参照しない】。
キャラクターは以下の指定に従うこと。
```

- **SeeArt の参照強度は 0.3〜0.5**（強すぎると絵柄でなく顔・構図までコピーされる）
- **参照画像は「原器の1枚」に固定**（生成物を次々参照にするとドリフトする）
- 効きが悪い時の英語併記: `same art style as the reference image, same artist,
  consistent line weight, muted colors, flat watercolor wash — do NOT copy the
  character, pose or composition`
- スタイルが暴れる時のネガティブ: 「3DCG風・厚塗り・グラデーション過多・
  高彩度・実写風・韓国ウェブトゥーン風・ゲームCG風にはしないこと」

## ■ 修正ポイント（現状2枚から学んだこと）

1. **文字は入れない**: プロンプトに「WINSのテキストは入れない」「ロゴ・文字・数字は描かない」と明示
2. **背景は白ではなく薄い暖色**: 「白背景」はやめて「暖かみのある光の中」「午後のWINS屋内」に
3. **おにぎりの透明袋**: ちゃんと「ビニール袋に入った」と明示（現状はほぼできている）
4. **年齢を誤魔化さない**: 「67歳のシワを自然に表現。怖くなく温かい」と毎回入れる
5. **顔面スペックを毎回貼る**: 同じキャラで複数生成するとき、毎回スペックを入れないと顔がバラバラになる
