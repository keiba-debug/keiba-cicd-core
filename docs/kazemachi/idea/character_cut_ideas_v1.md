# 全キャラ カット案集 V1 — イメージを膨らませるためのシーン案

> **作成日**: 2026-06-12
> **位置づけ**: イクコのプロンプト集（ikuko_image_prompts_v1.md）の姉妹編。
> こちらは「カット案」レベルで出しまくる。気に入ったものを選んでからフルプロンプト化する。
> **現状の課題**: オーディションフォルダはほぼ全部「単体立ち絵」。
> 群像劇なのに**関係性カット（2ショット以上）がゼロ**。シーン・関係性へ拡張する。

---

## ■ 全体方針

```
フェーズ1（完了済）: 単体立ち絵 = 「この人は誰か」
フェーズ2（これ）  : シーンカット = 「この人はどう生きてるか」
フェーズ3（次）    : 関係性カット = 「この人たちはどう繋がってるか」← 群像劇の本領
```

- 確定キャラ（ソラ35枚/リツ30枚/アキヒコ29枚）は立ち絵が十分 → シーンへ
- マキ（3枚・保留）は「絡みで戻ってくる」方針だった → 関係性カットが復帰の入口
- §11新軸（AI馬券・第0回）に使えるカットを優先マーク【§11】
