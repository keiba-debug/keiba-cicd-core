## 2. 各作家ハイライト

### カイ（構成）— 22案
- **控除率をラスボス化**: 負けの責任を構造に置き、キャラの尊厳を守ったまま「全員負ける」を見せ続ける
- **アキヒコ「想定内」シリーズ**: 毎週「想定内だ」→ 当たった週に初めて「想定外だ」と言う遅効性ギャグ
- **sim線とlive線の2本グラフ**: 「理論上の自分」と「現実の自分」の乖離が毎週のドラマ
- **キャラは毎週1人ずつ追加**: 「新キャラ登場」の引きが4週連続無料

### ユキ（感情）— 28案
- **連敗数・DD%を「感情パラメータ」としてセリフ生成AIに渡す**: 1敗目と5連敗目に同じトーンを言わせない
- **「まだ結果を知らない声」のアーカイブ**: 投票直後のTTS通知をキャラ音声化。結果後リアクションは世に溢れてるが、賭けた直後の声は誰も持ってない新ジャンル
- **イクコの負けた日は「おにぎりが一個多い」**: 感情を言葉でなく米の量で出す
- **「負けた日に絶対言わないこと」リスト**: 言わないことで人格を作る

### レイ（世界観）— 30案
- **機構は明かし、魂は隠す**: AIが実弾で買っていることは初日から開示。問いを「AIなのか?」→「AIになる前、誰だったのか?」へずらして15年前の層に接続
- **買わない日**: アキヒコの自動投票が毎年1日だけ沈黙する。ログが無いことがログ、という伏線
- **トリガー頻度のデータ較正**: 深層反応の条件はKeibaCICD過去データで出現頻度を実測してから決める。DBが謎の流量制御弁になる
- **プロトタイプの墓場**: sim5キャラの実資金曲線を「第0世代の遺品」として公開し、半年後にキャラの名前がつく——データが先、人格が後から追いつく

### シュウ（取材）— 35素材
- **「控除率を口に出すAIは存在しない」**: 「全員負ける」を看板にすること自体が、的中自慢で飽和した界隈での最強の差別化
- **「投票音のする家」**: 稼働中TTSをキャラボイス化した瞬間、取材コストゼロの生活音ドキュメンタリーが成立
- **税の判例が企画の真上にある**: 自動購入ソフトの網羅的購入で雑所得を認めた最高裁判例の射程に「AIの自動投票」は直撃。リスクであり同時にコンテンツ ※シズネ法務レビュー案件
- **5人同時デビューの罠**: 機能紹介になり人間観察にならない

### 3.2 第0回（非公開）の最小実装 — 部品は全部ある

```
土日: イクコのsim投票（fukusho_korogashi＋転がし） on 実レース
  → 結果JSON＋感情パラメータ（連敗数/DD%）
  → Claude API（イクコのペルソナ＋ユキの感情ルール）→ セリフ
  → VOICEVOX → wav
  → notify.py 経由でふくだのスピーカーから「買ったわよ」（投票音のする家）
  → （余力あれば）1枚絵＋音声＋資金グラフで1分動画（ffmpeg）
```

- notify-layer-roadmap の VOICEVOX アダプタ宿題と一石二鳥
- 実弾は不要。simでよい（実弾化はシズネ・ガードレール確認後）
