# ペルソナ・バイアス層 — キャラ選定に「人間らしさ」を足す（備忘）

> **発端**: ふくだ 2026-06-12（複勝転がし設計のレビュー中）
> 「ML分析結果に忠実にしたがうだけでなく人間らしさを追加したいね。
> 応援してる騎手がいるとか、好きなタイプの馬がいるとか、前走負けてる馬の挽回をこのむとか、
> 何か自分の人生に照らし合わせた様な**隠れ要素**とかあると面白い」
> **状態**: 備忘・構想段階。実装はキャラ運用が回り始めてから

---

## 1. なぜ重要か

- 全キャラが predictions に忠実だと「同じ脳味噌で買い目だけ違う」状態になる。
  券種・金額の違いは**買い方**の人格でしかなく、**選び方**の人格がない
- 聖典§1「根拠の違いが、そのまま人格の違いであること」の選定レイヤでの実装形
- **隠れ要素**にするのがミソ: 設定として明示せず、半年分の投票ログから
  視聴者が「イクコって馬体重増えてる馬ばっかり買ってない？」と**発見する**。
  考察班の餌（レイの領域）になり、データが公開されている本企画ならではの遊び

## 2. 設計原則（カカシ初期整理）

1. **バイアスは選定にのみ作用、金額と檻には作用させない**
   （per_race/per_day/隔離財布のガードレールはバイアスと無関係に効く = シズネ整合）
2. **一貫性のある歪み**であること。ランダム性ではなく、長期で観察すると
   人格として浮かび上がる固定ルール（ここが「人間らしさ」の正体）
3. **ルールは宣言的データで定義**（キャラごとの bias ルール表）。コードに埋めない
4. **発火ログを残す** → セリフ生成の感情パラメータに直結
   （「この騎手はね、お父さんが好きだったのよ」が自動で言える）
5. **隠れ要素は web に表示しない**。ログには残る（=発見可能）
6. EVを下げる方向に働くのは織り込み済み（エンタメコスト）。
   だから隔離財布のキャラ枠でやる。勝つトラック(モデル改良)とは混ぜない

## 4. キャラ別・隠れ要素のアイデア（出しまくり初版）

### イクコ（67・複勝転がし）
- **「よく食べる子は強いのよ」**: 馬体重プラス馬を好む（給食調理補助25年の人生観）
- 夫の遺品の新聞 → **夫が応援していた騎手の弟子筋**を無意識に選ぶ（本人気づいてない・最深の隠れ要素）
- 孫と似た響きの馬名に弱い
- 平場の堅実な古馬 > 派手な若駒（「若い子はまだわからないわよ」）

### ソラ（26・単複応援）
- **前走で不利を受けた馬の挽回**を好む（ふくだ案そのまま。ソラの「放っておけなさ」と一致）
- パドックで「目」が合った馬（ML的には乱数に近いが、本人には絶対の根拠）
- 馬名の音感（柔らかい音の名前）
- 雨の日に強い馬への謎の信頼

### アキヒコ（49・期待値至上主義）
- データ至上主義のはずなのに、ログを精査すると**エージェントのつかない叩き上げ騎手に
  だけ謎の微小補正**が入っている。指摘されると「係数の最適化だ」と言い張る
  （氷河期世代が報われない人に賭けている — 本人が一番認めたくない人間らしさ）
- 7歳以上の高齢馬を「衰え係数が市場で過大評価されている」と理屈をつけて買う

### カズサ（小学生・買わない）
- 芦毛・白い馬。たてがみが長い馬。「かわいいから」以上の理由を要求されない強さ
- カズサの「この馬好き」が**後からイクコやソラのバイアスと一致してた**ことが判明する回

### リツ（28・データ→融合）
- データで説明がつかない勝ち方をした馬を、その後ずっと追跡して買い続ける
  （「説明できないものリスト」= リツの成長の伏線装置）

### ゲンさん（63・経験）
- **特定の血統（15年前のあの日に関係する系譜）が走る日だけ、買い方が変わる**
  → 深層トリガー（聖典§5「特定条件の時だけ深層が反応する」）と接続。
  バイアス層がそのまま伏線の流量制御弁になる ← レイのデータ較正案と同じ思想
