# 買い方パターン カタログ（草案 v0 / Session 165・2026-06-20）

> **これは何**: ふくだが今まで伝えてきた「馬券の買い方パターン」を1枚に集めた一覧。
> 散らばっていた（コード `bet_templates.py` / 複数メモリ）ものをカカシが拾って草案化した。
> **目的（原点）**: パターンをここに集め、各レースで「この中のどれで買うか / 見送るか」を選ぶ。
> **ステータス**: ★草案★。ふくだが見て「これが抜けてる」「これは違う」を直す前提。
> 印の語彙: ◎=本命 / ○=対抗 / ▲=単穴 / △=連下 / Ⅲ=3番手連下（AI印の上位5頭）。

---

## 0. 読み方

各パターンは「**何を・どう組むか**」で書いた。「◎-○▲」は「◎を軸に、相手は○と▲」の意味。
- **保険** = まず当てて死に馬券を防ぐ役（手堅い）。
- **本線** = メインで狙う役。
- **ボーナス** = 当たれば大きい上乗せ役（当たらなくてもいい）。
- 検証ROIは「最新13ヶ月・全レースで機械的に買った場合の月別中央値」（2026-06-13 cache）。
  ★どれも100%未満＝長期では少し負ける（控除率の壁）。100%超は無い★（Session 165 確定）。

## A. 当てる系（単・複・馬連・ワイド = 少点数で手堅く）

### A-1. 本命党（単◎保険 + 馬連◎-○▲）
- 単勝◎を保険に置き、馬連 ◎-○、◎-▲ を本線。
- 死に馬券を防ぎつつ的中率重視。一番シンプルな本命狙い。

### A-2. 複勝堅実党（複◎ + ワイド◎-○）★最も損が小さい
- 複勝◎で土台、ワイド ◎-○ がボーナス。
- ローリスク。検証で**月別中央値87%＝全パターン中いちばん損が小さく・読める**。

### A-3. ワイド堅実党（ワイド◎流し + 三連複本線）
- ワイド ◎-○、◎-▲、◎-△ で的中率を担保 → 三連複を強気に絞る（◎-○▲-○▲△Ⅲ）。
- 「本の黄金パターン」。検証で月別中央値86%。

### A-4. ボーナス党（単◎保険 + 馬単◎→○▲）
- 単勝◎で的中担保、馬単 ◎→○、◎→▲（◎が1着固定）で順番まで当たれば上乗せ。

### A-5. 単勝二刀流（AI上位2頭の単勝）
- ◎と○の単勝を2点だけ。
- 「1番人気が弱い(AI印が低い)×妙味がある」レース限定なら有望だったが、★その条件判定は
  確定オッズ頼みで後知恵になる罠あり（実戦では消える）★。全レース版は単勝なので当たり外れが激しい。

### A-6. 勝負レート（単勝一本・勝負条件のレースだけ）★Session 166 検証済・採用方針確定
- **発火条件（4つ全部）**: ◎が勝率1位 ∧ 人気とのズレ≥3 ∧ EV≥1.3 ∧ 着差≤60。
  - = 「◎の単勝がおいしい」とAIが判断したレース。今のデータで**197件・月15件・1日1.66レース**。
- **やること**: その勝負レースで **◎の単勝を厚く** 買う（勝負レート）。
- **他のレースでは単勝を買わない**（複勝・comboは別レイヤーで普段どおり）。
- **複勝は足さない**（保険にならず薄利で全体を食う・下の検証参照）。
- 検証（最新13ヶ月 cache・単勝600円固定）:
  - 勝負197レースだけ単勝 = **収支 +9,780円 / Flat ROI 108.3% / 的中11.7%**（唯一プラス）。
  - 他レースも薄く単勝を足すと **逆に赤字**（薄い単勝が全体を食う）。
  - 勝負Rに複勝を足すと **収支もROIもまっすぐ下がる**（複0=+9,780 → 複600=-19,140）。
    安心感（月別ばらつき↓）と引き換えに黒字そのものが消える。**保険は不要**。
- ★性質★: 中身は **5〜19倍のソコソコ人気の本命が9割**。たまに来る大当たり月で控除率を超える
  「当たればデカいが当たりが薄い」型。**安定戦略ではなく、勝負レートの引き金**として使う。
- ★これは「見送り」ではない★: 複勝・comboは全レース普段どおり買い、**単勝という買い方だけ**を
  勝負レースに集中させる「単勝の張り場の選別」。Session 162-165 で害確定した見送りゲート
  （買い目全体を確定オッズで降りる）とは別物（[[feedback_odds_gate_hindsight]]）。

## B. 当たる系（三連複・三連単 = 広く拾う高配当・夢枠）

### B-1. 三連複1頭軸流し（◎-相手総流し）
- ◎を軸に固定、2列目3列目を相手（○▲△Ⅲ）で総流し。印の付いた上位5頭で完結。
- 検証で月別中央値85%。時々大きく跳ねる月がある（上振れ型）。

### B-2. 本命党フォーメーション（三連複1頭軸保険 + 三連単◎○▲BOXボーナス）
- 保険：三連複 ◎-相手総流し（◎が3着内に来れば広く拾う）。
- ボーナス：三連単 ◎○▲のBOX（この3頭で順番含めて決まれば爆発）。
- 「◎○▲で決まったのに三連複だと安い」問題を、三連単BOXで補う。本命決着で両取り。
- ★三連単の厚み（weight）を変えると「安定」⇄「でかく勝つ」が動く。ふくだ要調整★。

### B-3. 三連単ロマン党（単◎保険 + 三連単◎→○▲△→○▲△Ⅲ）★夢枠
- 単勝◎を薄く保険に、三連単 ◎を1着固定→2着○▲△→3着○▲△Ⅲ のフォーメーション。
- -EV承知の遊び枠。当たれば高配当、外れても痛くない少額。★隔離財布で回す前提★。

## C. ふくだが伝えたが「文書に断片しかない」パターン（★要・拾い直し）

### C-1. ◎を2着付けにして配当を跳ねさせる（[[maru-second-place-formation]]）
- 抜けた1番人気◎を「1着」でなく「2着」に固定し、1着を伏兵▲に据える三連単フォーメーション。
- 例：▲→◎→相手、のように◎の置き場を2着にずらして配当を上げる。
- ◎は信頼するが、1着固定だと安いので2着付けで妙味を出す工夫。本命フォメと真逆の発想。
- ★伏兵(▲)を当てる精度が要る。「激走馬を見つけるモデル(sirius)」待ちの構想★。

### C-2. ○の頭を捨てる／単勝多点（[[wp-role-split-strategy]]）
- 「勝ち切る馬」と「好走どまりの馬」を分けて、○は3着付けに回し1着固定から外す役割分化。
- 単勝を多点で買う形も検討した。
- ★検証では本番不採用になった（条件が後知恵で消えた）が、発想は記録として残す★。

### C-3. 三連単フォーメーション × オッズの歪み（[[sanrentan-distortion.md]]・Session 110）

- 1番人気3.0倍未満 × 歪み2-3 の条件で4点買い。ボーナス枠として月3万円の構想。
- ★これも具体パターンはメモリに眠っていて、本番に繋がっていない★。

## D. このカタログの使い方（原点のテーマ）

1. 上のパターンを **「自分の買い方の引き出し」** として固定する。
2. 各レースで「このレースは A-3 で行く」「これは見送り」と **選ぶだけ** にする。
3. どのレースでどのパターンを選ぶかの「選び方」は次に決める（カタログが固まってから）。

★今までは「配分計算（サイザー）」を毎回いじって複雑になっていた。原点＝パターンを決めて選ぶ、に戻す★。
