# 双馬式 展開読み → ML特徴量 抽出仕様

> 双馬毅『双馬式 誰も言わなかった 馬券富豪の展開読み』(革命競馬, 2019)
> VLM読み取りノート(114p)を Claude が ML特徴量設計に落とし込んだもの。
> **展開(隊列・ペース)を予測する本**。レース質マトリックス([[レース質マトリックス_ML特徴量]])が「ペースを入力として受け取る」のに対し、
> 本書は **その"ペース/隊列"を テン1ハロン持ちタイム から生成する** = 4冊統合の要石。
> データ採取期間: 2015/1/4〜2019/9/29。原文/画像は手元非公開、本データは型を消化した派生物。

---

## 0. コア発想 — 通過順を信じるな、テン1ハロン持ちタイムで隊列を当てる

著者の主張: 過去の**通過順([1-1-1]等)は誤り**を含む(展開・枠・事故で歪む)。代わりに
**テン1ハロン(発走直後200m)の"持ちタイム"** を見れば「**隠れた逃げ・先行馬**」が分かり、隊列=展開が読める。

- 例: A馬 通過順[111] だがテン1F 12.6〜12.9 / B馬 通過順[333]だがテン1F 12.1。
  → 一般人はAが先行と読むが、**B馬の方がテンが速く十中八九前に行く**。
- テン1F持ちタイムは**JRA公式非公表**で新聞馬柱に載らない=多くのファンが無視→エッジになる(「競馬情報局/スマート出馬表」で取得、と本書)。

> ML的含意: 各馬の **テン1F持ちタイム** を特徴量化すれば、レース質マトリックスが必要とする
> 「①逃げ・先行馬の割合」「lead_side」「rq_pace」を**データから生成**できる。

---

## 1. コア特徴量 — テン1ハロン持ちタイム

| 特徴量 | 定義 | 用途 |
|---|---|---|
| `tenF1_best` | 過去走のテン1F(最初の200m)タイムの**最速/代表値**(直近N走) | 先行力・逃げ propensity |
| `tenF1_rank` | レース内での `tenF1_best` 順位(速いほど前) | **隊列予測**: 1位=本命の逃げ・先行 |
| `tenF1_top_flag` | レース内テン1F 1位馬か | 単独最速=逃げ濃厚 |

**距離補正(必須)**: テン1Fは距離で基準が動く。本書の目安 **1200m≈12.8秒 / 2000m≈12.1秒**
(短いほどテンが速い)。→ `tenF1_best` は**距離正規化**してからレース内比較する。

**隊列予測ロジック**: 全出走馬の `tenF1_best`(距離補正後)を並べ、上位=前、下位=後ろ で**想定隊列**を作る。
これが レース質マトリックスの `lead_side`(内枠主導/外枠主導)と `rq_pace`(ハイ/スロー)の**直接の入力**になる。

---

## 2. テン3ハロン + 延長血統(距離変化への適性)

- **テン3F(発走直後600m)** = 距離延長/短縮時の**前半ペース変化への適性**を見る。
  単純な「33秒台=テン速い」ではなく**内訳(1F毎)**が重要。距離延長で前半が相対的に緩む/速くなるのを捌けるか。
- **延長血統(距離延長が得意な種牡馬/血統)** = 第3章の核。`ext_pedigree_score`。
  - 例(本書): ハービンジャー産駒は**テン3Fが速く**、距離短縮でペースアップに追走苦しい(ディアドラ 香港C2000m→中山記念1800m短縮で6着)。逆に延長で一変する血統がある。
  - 「短縮ローテ後、延長で一変する馬」= ローテ×血統の交互作用シグナル。
- → 特徴量: `ten3F_best`(距離補正) と `ext_pedigree_score`(血統×延長フラグ)。レース質マトリックスの `rq_rotation`(短縮/延長)を血統で精緻化。

---

## 3. テン1F順位 × 枠 の交互作用(双馬式の馬券核心)

**双馬式 枠定義: 内枠=1〜3枠 / 外枠=6〜8枠**(中枠=4〜5)。この3値で枠を binning。

核心ルール: **「テン1F 1位馬 × そのコースの有利枠」= 鬼に金棒**(最強シグナル)。
逆に テン1F 1位馬が不利枠に入ると評価を下げる/全滅もある(例: 小倉芝2600m 外枠のテン1位馬は勝率0%)。

→ 特徴量: `tenF1_top_x_favorable_frame` = (テン1F1位フラグ) × (当該コースの枠有利度)。

---

## 4. コース別 テン×枠 傾向テーブル(抜粋・要再キャリブレ)

各コース/距離で「テン1F持ちタイム上位馬」を**内枠/外枠別に集計**した枠別成績。`course_ten_frame_bias` 辞書化。

| コース | 傾向 | 数値メモ(テン1F上位馬の枠別) |
|---|---|---|
| 福島芝1200 | **内枠断然有利** | 内枠 勝率11.0%/単回148 vs 外枠7.3%/51 |
| 福島芝1800 | 内枠有利 | 内枠8.3%/単回102 vs 外枠6.5%/26 |
| 中京芝2000 | **外枠有利**(収益) | 外枠 単回89 / 内枠 単回44 |
| 中京芝2200 | 外枠有利 | 内枠勝率は高いが外枠が妙味 |
| 中京ダ1200 | 内枠有利(5枠から不利) | 内枠9.3% vs 外枠6.2% |
| 阪神ダ2000 | 外枠有利 | 外枠10.9% vs 内枠4.1% |
| 新潟ダ1200 | 外枠有利(斜めゲート) | 外枠14.4% vs 内枠7.9% |
| 小倉ダ1000 | 内枠有利・外枠不利 | 内枠13.2% vs 外枠10.4% |
| 小倉芝2600 | **内枠有利・外枠全滅** | 外枠テン1位馬 勝率0% |

> ⚠ 数値はVLM由来の目安。期間2015-2019・テン1F上位条件付き・母数小のセルあり。**JRD実データで再集計**前提。
> コース辞典([[project_keiba-course-dict]])の枠別成績と**テン条件付き**で突合すると精度↑。

## 5. ★統合 — 展開予測パイプライン(5冊を繋ぐ背骨)

双馬式が**ペース/隊列の生成器**、他3冊が**それを使う側**:

```
[双馬式] 各馬 tenF1_best(距離補正) → 想定隊列(誰が前)→ 想定ペース(rq_pace)・lead_side
        + ext_pedigree_score(延長血統) → rq_rotation 精緻化
                    │
                    ▼
[レース質マトリックス] (枠/脚質/ローテ/ペース)レース質ラベル ← ペース入力が埋まる
                    │
                    ▼
[上がりXハロン] 能力3軸(スピード/スタミナ/パワー)を **想定ペースで de-confound**
                    (上がりタイムはペース依存 → 双馬式の想定ペースで条件付き正規化)
                    │
                    ▼
[スマート出馬表(亀谷)] 人気ランク別集計でノイズ除去 + コース傾向×直近傾向 で最終バイアス補正
```

→ 統合特徴量: `pace_scenario`(双馬式由来) を軸に、レース質ラベル・能力3軸・コースバイアスを条件付け。
詳細は別途 **4冊横断統合spec** で(本書はその"展開"ピース)。

## 6. KEIBA-CICD 接続(候補特徴量カタログ)

| 特徴量 | 生成元 | 必要データ | 種別 |
|---|---|---|---|
| `tenF1_best` / `tenF1_rank` / `tenF1_top_flag` | §1 | 各走の**テン1F(前半200m)タイム** | 馬→レース |
| `ten3F_best` | §2 | テン3F(前半600m)タイム | 馬 |
| `ext_pedigree_score` | §2 | 種牡馬/血統 × 延長フラグ | 馬 |
| `souma_frame`(内1-3/中4-5/外6-8) | §3 | 枠番 | 馬 |
| `tenF1_top_x_favorable_frame` | §3-4 | テン1位 × コース枠有利度 | 馬×レース |
| `course_ten_frame_bias` | §4 | 場×距離の辞書 | コース固定 |
| **`pace_scenario` / `lead_side` / `pace_high_flag`** | §5 | 全馬のtenF1集約 | **レース(展開予測)** |

**接続メモ**:
- 要は**テン1F/テン3F(前半ハロンタイム)**。JRDB(`data3/jrdb`)に前半ハロン/テンがあるか要確認(無ければ通過タイム・コーナー通過から近似)。
- 「スマート出馬表」(競馬情報局)がテン持ちタイムの出所。手元データで同等を作れるか確認。
- レース質マトリックスの `pace_score`(5要素)の①は、この `tenF1` 集約で**データ駆動に置換**できる。

## 7. 注意
- **リーク厳禁**: tenF1_best は対象レース"より前"の走のみ。pace_scenario は確定枠順+出走馬の過去テンから事前計算(結果不使用)。
- OCR目安(枠別成績の数値)。期間2015-2019=馬場造形が今と違う可能性([[レース質マトリックス_実践編_ML特徴量]]§4 非定常性)→近年で再集計。
- 通過順は捨てず、**テンタイムと併用**(著者も通過順は参考程度に残す)。
- 巻頭13ページは万馬券ギャラリー(実績写真)=特徴量無関係、本文は0014以降。
