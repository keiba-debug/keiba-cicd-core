## 3. 初角までの距離(連続特徴量)

ペース・先行負荷の主要ドライバ。**短い→ペース緩む/内枠先行有利、長い→ペース速い/外枠差し有利**。
閾値の目安: **約350m以下=短(内枠・先行・スロー) / 長=(外枠・差し・ハイ)**。本書記載の実値(目安):

| コース | 初角まで(m) |
|---|---|
| 東京芝1400 | 343 |
| 東京芝1600 | 543 |
| 東京芝2000 | 126 |
| 函館 芝2000 | 約475 |
| 福島 芝2000 | 約505 |
| 小倉 芝2000 | 約472 |
| 中山 芝1600 | 約240 |

> `dist_to_first_corner_m`(連続) と `first_corner_short_flag`(≤350m) を特徴量化。
> メカニズム: テン2F目がコーナーに掛かる(短)→息が入りペース緩む / 直線(長)→雁行で息入らず速くなる。

## 4. ⚠ 非定常性 — 枠バイアスは年で反転する(最重要)

東京芝など馬場造形の変化で、**枠バイアスの符号が経年で反転する**:

| 期間 | 内枠(1-4枠) 単回/複回 | 外枠(5-8枠) 単回/複回 | 傾向 |
|---|---|---|---|
| 2018〜2020 | 106 / 85 | 45 / 61 | **内枠有利** |
| 2021〜 | 69 / 55 | 133 / 83 | **外枠有利** |

**ML上の含意(必須対応):**
- 枠/脚質バイアス系特徴量は **近3年のローリング窓**で算出(固定の過去10年集計は符号が逆になり毒)。
- コースごとに「馬場造形レジーム」のブレイク点を持ち、レジーム前後を分けるか recency weight を掛ける。
- 重賞の過去傾向データは**再現性スコア**(§6)でウェイトしてから使う。
- 本書の集計が2021-2023基準である点に注意(=2021以降レジームの値)。

## 5. 隊列(主導) — メンバー構成から計算するレース単位特徴量

**どちらの枠の先行馬が隊列を作るか**でレース質が大きく動く。`lead_side` ∈ {inner, outer}。

| | 内枠主導(速い先行馬が内) | 外枠主導(速い先行馬が外) |
|---|---|---|
| 馬群 | 縦長になりやすい | 凝縮しやすい |
| 効く馬場 | 前残り馬場で**先行有利拡大** | 差し馬場で**差し有利拡大** |
| 外枠差し | 超高速〜高速で不利大 | 縦長薄いと「外枠・差し」プラス |
| 内枠差し | 流れに乗り前を取れる(好走) | 馬群外に出やすいメリット |

判定入力: 各馬の(枠, 推定先行力)。`n_front`(先行馬数)・先行馬の枠分布から `lead_side` と
`field_pace_pressure` を生成。16頭立て標準構成 **逃げ:先行:差し:追込 = 1:4:7:4**。

## 6. 構造系の事前分布(妙味・クラス・世代・再現性)

### 6-1. 妙味の向き(オッズ補正)
- **先行馬=過剰人気 / 差し馬=過剰不人気**(競技は先行有利→人気が織り込む)。
- → `style_value_adj`: 差し馬に+、先行馬に−の事前。特に**ダート上級条件の差し馬**は妙味大。

### 6-2. クラス×脚質(ダート差し有利の構造)
クラス上昇で先行占有が変化(逃げ率): 新馬未勝利 51.8% → 1勝 39.5% → 2勝 28.9% → 3勝 32.9% → OP 36.7%。
能力拮抗する上級条件ほど「先行有利が薄れ差し馬の能力が出る」。`class_level × surface` を交互作用項に。
脚質傾向が大きく動くコース: 阪神ダ1800/2000・中山ダ1800・中京ダ1800/1900(下級↔上級の境界)。

### 6-3. 世代限定戦(短縮差し有利)
2歳/3歳限定(新馬未勝利除く)の芝短距離・ダートは「内(外)・差し・短縮・ハイ」が基本。
- 出現条件: 芝1500m以下(特に1200) or ダート / 9頭以上 / 前走先行馬多 / ローカル。
- ハイペース判定に **PCI<50**(前傾)。前走初角10番手以下が複勝率最高(差し経験馬=能力上位)。
- 2歳ダートは **短縮ローテ勝率18.8%/複勝31.3%**(同5.1/25.6・延長8.0/24.0を圧倒)。
- `gen_limited_flag` × `prev_corner_pos` × `rotation` を特徴量化。

### 6-4. 再現性スコア(重賞の過去傾向の信頼度)
5要件: ①毎年開催 ②施行条件/時期不変 ③メンバー質安定 ④極端バイアス無 ⑤レース質根幹安定。
GII以上で高い。`race_repeatability_score` を作り、過去傾向データの利用ウェイトに。
**条件替わり減点**(京都改修・宝塚記念の開催週ズレ 2021-2022 等)を必ず反映。

## 7. ローテ効果(本編§補強)

ローテ別成績(2021-2023, 勝率): 芝 短縮7.5/同8.4/延長6.1 ・ ダ 短縮6.5/同8.4/延長5.8。
→ **同距離が最も勝率高い**が、妙味は短縮差し。`rotation` 単体でなく `rotation × race_quality一致` で効く。

- **距離短縮3効果**: ①テン速く後方位置取り容易 ②持続力(高速持続/上がり) ③操縦性。有利=差し有利/上がり掛かる/加減速要のレース。
- **距離延長3効果**: ①テン速い ②平均ラップ適応 ③前方位置取りやすい。有利=先行有利/速ラップ要/一貫性のレース。

## 8. 反レース質ストック(能力シグナル抽出)

- 近走で**不利なレース質に反して凡走**した馬 = 能力が隠れている → ストックし、合致時に巻き返し狙い。
- 近走で**有利なレース質に合致して好走**した馬 = 過剰人気で軽視。
- → 特徴量 `prev_race_quality_fit`(前走のレース質と馬属性の一致度)。**不適合下の好走**を正の能力シグナル、
  **適合下の好走**を割引シグナルとして符号付きで持つ。本編§の `rq_match_score` の「履歴版」。

## 10. 実装メモ・注意

- §1の黄金パターンは**そのまま決定表**にできる最高の素材。まず信頼度高い数本(東京芝2000/阪神中距離/小倉ダ1700/芝発走ダート)から実装し、コース辞典の脚質別回収値で方向検証。
- **非定常性(§4)を最優先で設計に織り込む**。固定長期集計は符号反転で逆効果。recency窓・レジーム分割は必須。
- 含水率の場×距離別ニュアンス(小倉ダ1700の反転、芝発走ダート7%以下など)を持つ。本編§2-3の全国一律バンドに**コース別補正**を重ねる。
- 数値はVLM由来。初角まで距離・含水率閾値・脚質別勝率は「目安」。実装時はコース辞典/JRDB実数で再キャリブレーション。
- リーク注意: `lead_side`・`field_pace_pressure` は確定枠順+出走馬から事前計算可(結果不使用)。`frame_bias_3yr` は対象レース日より前のみ。
