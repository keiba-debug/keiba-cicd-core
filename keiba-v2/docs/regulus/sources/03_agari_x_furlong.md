# 上がりXハロン → ML特徴量 抽出仕様

> 安井涼太『安井式 上がりXハロン攻略法』(革命競馬, 2022.10)
> VLM読み取りノート(99p)を Claude が ML特徴量設計に落とし込んだもの。
> レース質マトリックス([[レース質マトリックス_ML特徴量]])が「レース環境(枠/脚質/ペース)」の軸なのに対し、
> 本書は**馬の能力を3次元(スピード/スタミナ/パワー)に分解して測る軸**。両者は直交し、掛け合わせると「能力×環境適合」になる。
> ⚠ VLM読みで3ページ(0032/0039/0070)がthinkingループで汚染。補正定数は**目安＝実データで再キャリブレ前提**。原文/画像は手元非公開。

---

## 0. コア発想 — 上がり3Fを分解し3能力に対応づける

著者の主張: **「上がり3F(=ラスト600m)を見るな」**。3Fは瞬発力の混成で中途半端。代わりに区間を割り、各区間を別々の潜在能力に対応させる:

| 区間 | 略 | 対応する潜在能力 | 速い方が良い? | ML上の扱い |
|---|---|---|---|---|
| ラスト **2F**(400m) | 上がり2F | **スピード** | ✅ 低い=速い=良い | `ability_speed` |
| ラスト **1F**(200m) | 上がり1F | **スタミナ** | ❌ **高い(遅い)=良い** ⚠逆 | `ability_stamina` |
| ラスト **4F**(800m) | 上がり4F | **パワー** | ✅ 低い=速い=良い | `ability_power` |

> 各区間は**レースのハロンラップ(1F刻みタイム)の末尾N個の和**から計算できる＝JRDB等にラップがあれば機械的に算出可能。
> 3F単独ではなく**3軸ベクトル `ability[speed,stamina,power]`** に展開するのが本書のキモ。

---

## 1. 各メトリクスの計算式(=特徴量の作り方)

### 1-1. スピード = 上がり2F(着差補正)
- **算出**: レースラップ最後の2数値の和。**2着以下は勝ち馬とのタイム差をプラス**(着差補正)。
- **対象期間**: 2-3歳戦=過去全戦 / 古馬戦=近4走。その中の**最速値**を持ちタイムとする。
- **閾値(能力シグナル)**: 新馬戦 **上がり2F ≤ 22.5秒 = 名馬の証**。芝1600m+新馬395R中58R(15%)が該当→うち27の勝ち馬が後の重賞で好走。≤21.5は超一線級(リバティアイランド21.1等)。
- **効く条件**: 短距離戦・直線(直線長=約400m=2F=全速区間)。

### 1-2. スタミナ = 上がり1F(クラス補正) ⚠**遅いほど高評価**
- **算出**: レースラップ最後の1数値 + **クラス補正**。**着順補正はしない**(連対馬は同値扱い)。
- **対象期間**: 2-3歳=全戦 / 古馬=近4走。補正後で**最も遅い値**をスタミナ評価とする。
- **逆転の発想**: ラスト1Fまで失速せず粘れる=持久力。**「遅い1F」を弱さと誤認しないこと**(特徴量の符号を反転させない)。生理学的根拠=15秒以下は有酸素依存で持続力勝負。
- **効く条件**: 芝重馬場・長距離戦・ダート戦。型例: ゴールドシップ/キタサンブラック/ディープボンド。

### 1-3. パワー = 上がり4F(着差+馬場+距離補正)
- **算出**: レースラップ最後の4数値の和 → **着差補正**(2着以下は勝ち馬とのタイム差プラス) → **馬場補正**(表2) → **距離補正**(基準値表3でコース距離標準化)。芝戦は過去の芝のみ/ダート戦はダートのみ対象。
- **主張**: 「**レースが動くのは上がり4F目から**」。3Fはスパート開始点を捉えきれない。生理学的に4F(~48秒)は乳酸系の持続時間に合致＝本質的。
- **効く条件**: 直線に坂のあるコース(中山/中京/阪神)・中距離以上。型例: サートゥルナリア(補正値42.2でトップ)。

## 2. 補正テーブル(そのまま正規化に使える数表) ※OCR目安・要検証

### クラス補正(上がり1Fスタミナ用に加算)
| クラス | 補正 | クラス | 補正 |
|---|---|---|---|
| 新馬・未勝利 | 0 | OP特別(L含) | 0.4 |
| 1勝 | 0.1 | GIII | 0.5 |
| 2勝 | 0.2 | GII | 0.6 |
| 3勝 | 0.3 | GI | 0.7 |
| 2歳限定戦 | −0.2 | 3歳限定戦 | −0.1 |

### 馬場差補正(上がり4Fパワー用)
| 馬場 | 芝 | ダート |
|---|---|---|
| 良 | +0 | −0.4 |
| 稍重 | +0.4 | −0.8 |
| 重 | +0.8 | −1.2 |
| 不良 | +1.2 | −1.2 |

### 距離基準値(上がり4Fパワー用・標準化)
- 芝: 1000m=43.8 / 1200m=45.8 / 1400m=46.8 / … / 3600m=50.5
- ダート: 1000m=47.5 / 1150m=48.1 / 1200m=48.8 / … / 2500m=51.1
- 距離区分: 短距離~1400 / マイル1500-1800 / 中距離1900-2400 / 長距離2500~

> ⚠ 上記定数はVLM由来で飛び番・読み違いの可能性。**実装時はJRDB実ラップで各距離・馬場の基準値/補正を自前回帰し直す**のが正道(本書の構造＝「クラス・馬場・距離で標準化した残差」を能力とみなす、という考え方が本体)。

## 3. コース別 能力デマンド(スピード/スタミナ/パワーの重み)

第5章は10競馬場×距離ごとに3能力の重要度を★(1〜3 or 1〜5)で評価。`course_demand[speed,stamina,power]` の辞書になる。例:

| コース | スピード | スタミナ | パワー | 備考 |
|---|---|---|---|---|
| 東京芝1600 | ★3 | ★3 | ★3 | 全要素最高(大箱・直線525.9m) |
| 東京芝1800 | ★3 | ★2 | ★2 | スピード寄り |
| 東京ダ2100 | ★4 | ★4 | ★3 | スタミナ&スピード |
| 中山芝1200(外) | ★3 | (高) | ★3 | 急坂310m/高低差5.3mで短距離でもスタミナ比重↑ |
| 中山ダ1200 | ★3 | ★3 | ★2 | |

→ **適合スコア** `ability_fit = Σ course_demand[k] × horse_ability[k]`(k∈{speed,stamina,power})を特徴量化。
馬の3軸プロファイルと当該コースの要求プロファイルの内積＝「この馬がこのコースに向くか」。

## 4. ⚠ 妙味の罠(model prob ≠ market edge)

第1章の実証が重要な教訓:
- **上がり3F順位1位**: 勝率32.3% / 複勝率65.4%(結果と強相関)。
- **だが 前走上がり3F順位1位**: 勝率14.2% / **単回収72円**(控除率20%下で負け) → **既にオッズに織り込まれ妙味なし**。

含意:
- 生の上がり3F(やその順位)は**勝率予測には効くが、期待値(EV)では稼げない**(人気に織り込み済み)。
- 本書の価値は、**分解(1F/2F/4F)＋補正(クラス/馬場/距離)で「市場がまだ見ていない残差能力」を作る**こと。ここに残差αの可能性。
- ML設計でも「勝率モデルの特徴量」と「EV/妙味モデルの特徴量」を分け、後者では**人気で説明できない上がり残差**を使う。

## 5. KEIBA-CICD 接続(候補特徴量カタログ)

| 特徴量 | 生成元 | 必要データ | 種別 |
|---|---|---|---|
| `ability_speed`(補正上がり2F・近Nの最速) | §1-1 | レースハロンラップ末尾2・着差・クラス | 馬(履歴) |
| `ability_stamina`(補正上がり1F・最も遅い値) | §1-2 | ラップ末尾1・クラス補正 ⚠符号注意 | 馬(履歴) |
| `ability_power`(補正上がり4F) | §1-3 | ラップ末尾4・着差・馬場・距離基準 | 馬(履歴) |
| `ability_profile[3]`(3軸ベクトル) | §0 | 上記3つ | 馬 |
| `course_demand[3]` / `ability_fit` | §3 | 場×距離の★ + 馬の3軸 | 馬×レース |
| `agari3f_priced_in_flag`(妙味なし印) | §4 | 上がり3F順位 vs 人気 | 検証/EV用 |
| 新馬 `speed_elite_flag`(上がり2F≤22.5) | §1-1 | 新馬戦ラップ | 馬(2歳評価) |

**接続メモ**:
- 必要なのは**1F刻みのレースラップ**。JRDB(`data3/jrdb`)に後3F/ハロン情報があるか要確認。無ければ通過タイムから近似。
- レース質マトリックスの `umachara`(馬キャラ=位置取り由来)とは**別系統の能力指標**。両方を持つと「位置取り型 × 能力3軸」で表現力が増す。

## 6. 実装メモ・注意
- **3軸分解 → クラス/馬場/距離で標準化**という骨格が本体。補正定数(§2)は目安、JRDB実データで回帰し直す。
- **上がり1Fの符号に注意**(遅い=スタミナ高=良い)。素朴に「小さいほど良い」で入れると逆効果。
- VLM汚染ページ(0032/0039/0070)あり。该当の数表は原本/データで再取得推奨。
- リーク注意: 能力は**過去走から**作る(対象レース不使用)。クラス/馬場/距離は事前確定でOK。
- **ペースとの交絡**: 上がりタイムは前半ペースに依存(スロー→上がり速い)。レース質マトリックスの `rq_pace` で**ペース条件付き正規化**してから能力化すると精度↑(→4冊横断§で統合)。
