# レース質マトリックス → ML特徴量 抽出仕様

> 立川優馬『レース質マトリックス ―競馬は全て二択である―』(ガイドワークス, 2021)
> VLM読み取りノート(93p) を Claude が ML特徴量設計に落とし込んだもの。
> 用途: KEIBA-CICD 予測モデルの **レース質ラベル生成** と **馬キャラ派生特徴量**。
> 原文転記・画像は手元非公開。本書は型を消化した派生物(オリジナル)。

---

## 0. 位置づけ — コース辞典との補完関係

| 資産 | 性質 | ML上の役割 |
|---|---|---|
| `keibajo_course_constants.csv` / `_bias_long.csv`(コース辞典2) | **実証統計**(各コースの枠別/脚質別の実勝率・回収) | 事前確率・固定バイアス |
| **本書(レース質マトリックス)** | **ルールエンジン**(条件→レース質ラベルを出す論理) | 当日条件で動的に決まる特徴量 |

コース辞典が「このコースは内枠が何%」という**静的な地形バイアス**を与えるのに対し、
本書は「**馬場状態×ペース×メンバー構成×風**を入れると、そのレース固有の有利属性(レース質)が
4軸2択で出力される」**動的ラベラ**を与える。両者を掛けると「地形ベース × 当日補正」になる。

## 1. コア概念 — レース質 = 4軸×2択ラベル

1レースを次の4軸で分類する。各軸は2値。①②は全レース必須、③④は条件があるときのみ付与。

| # | 軸 | 値(2択) | 必須性 | 特徴量案(列名) |
|---|---|---|---|---|
| ① | 枠 frame | 内枠 / 外枠 | 常時 | `rq_frame` ∈ {in, out} |
| ② | 脚質 style | 先行 / 差し | 常時 | `rq_style` ∈ {front, closer} |
| ③ | ローテ rotation | 短縮 / 延長 | 任意 | `rq_rotation` ∈ {short, ext, none} |
| ④ | ペース pace | ハイ / スロー | 任意 | `rq_pace` ∈ {high, slow, none} |

**馬側との突合**: 各出走馬に (枠, 脚質, 今走ローテ) が定まるので、
`rq_match_score` = レース質ラベルと馬属性の一致度(後述の座標図ロジック)を特徴量化できる。
本書の「買う馬/消す馬」判定は本質的に **レース質ラベル × 馬属性 の一致度ランキング**。

> 換算定数: **1馬身 = 0.2秒**(差し/先行の到達可否計算の基礎)。

## 2. レース質ラベル生成ルール(=特徴量エンジン)

### 2-1. 芝の基本レース質(馬場状態6分類)

馬場状態を判定 → 基本レース質ラベルを引く。閾値は1600m基準の目安。

| 馬場状態 | 全体時計(1600m) | 上がり3F | 基本レース質 | 主な発生状況 |
|---|---|---|---|---|
| 超高速 | ~1:32前半 | ~34秒台前半 | **内枠・差し・延長** | 開幕週(夏秋)・散水少 |
| 高速 | ~1:33前半 | ~34秒台前半 | **内枠・先行**(短直線) / **外枠・差し・スロー**(長直線) | 開幕週(春冬)・東京京都良 |
| フラット | — | — | コースのもつレース質を優先 | 主要4場は高速後に継続 |
| 内荒れ | — | — | **外枠・差し**(外差し) | ローカル開催後半 |
| 荒れ | — | — | **外枠・先行** | ローカル後半・冬中山 |
| 内空け | — | — | **内枠・先行**(悪化時 外枠・先行) | 梅雨・秋雨の不良馬場 |

### 2-2. ダートの基本レース質(馬場状態4分類)

判定指標 = **(逃げ馬の上がり3F) − (上がり最速馬の上がり3F)** [秒]。施行1400~1800m基準。

| 馬場状態 | 上記差の閾値 | 基本レース質 | 発生条件 |
|---|---|---|---|
| 先行馬場 | ~1.2秒 | **外枠・先行** / 内枠・先行(1400m以上) | 湿潤期・凍結防止剤散布の稍重~不良 |
| フラット | 1.3~2.0秒 | コースのもつレース質を優先 | 通常時 |
| 差し馬場 | 2.1秒~ | **差し・短縮** | 乾燥期・全体時計が遅いタフなダート |
| 雨馬場 | (含水率10%超) | **先行・延長** | 雨雪の重・不良(脚抜き良い) |

> ダート差し馬場は「全レース質中で最も高頻度」。常時デフォルト候補として持っておく。

### 2-3. 馬場硬さ指標の閾値(事前にバイアスを察知)

**クッション値(芝)** — JRA金曜発表。Clegg Hammer(2.5kg・45cm落下)由来。

| クッション値 | レース質バケツ | 備考 |
|---|---|---|
| 8.9以下 | 低速馬場(上がり遅・全体遅) | |
| 9.0~9.9 | フラット | |
| 10.0~10.9 | 高速馬場(上がり速) | |
| 11.0以上 | 超高速馬場(上がり非常に速) | |

- 表層硬さ別: 12以上=硬め / 10~12=やや硬め / 7以下=軟らかめ。
- **コース補正**: 中山は約+1.0高めに出る / 東京は含水率高く低めに出る。→ コース固定オフセットを特徴量に。
- アナログ測定のため日替わりブレあり(例: 金9.6→土8.8→日9.7)。**3日移動平均/前開催比**を併用推奨。

**含水率** — 芝とダートで基準が別。

| 区分 | 芝 | ダート |
|---|---|---|
| 良/高速 | 9以下=良 | 10.0%以上=高速 |
| 中間 | — | 9.9~6.0=フラット |
| 低速 | — | 5.9~3.0=低速 |
| 超低速/不良 | 14以上=不良 | 2.9以下=超低速 |

**テン1F速度(ダート短距離1000~1400mの逃げ馬判定)**: ~12.0秒=速い / 12.0~12.5=通常 / 12.6~=遅い。

### 2-4. コースのもつレース質(コース定数5要素)

馬場がフラットのときは地形が支配。下表は本書記載の分類(コース辞典CSVで実数検証可)。

| コース | 直線距離 | 急坂 | 最終コーナー | 主な発走地形 |
|---|---|---|---|---|
| 札幌 | 短 | 平坦 | 通常 | ポケット(芝1500) |
| 函館 | 短 | 平坦 | スパイラル | — |
| 福島 | 短 | 平坦 | スパイラル | 芝発走ダート(ダ1150) |
| 新潟(内) | 普通 | 平坦 | 通常 | — |
| 新潟(外) | **長**(日本最長) | 平坦 | 通常 | — |
| 東京 | **長** | 平坦 | 通常 | ポケット(芝2000)/坂発走 |
| 中山 | 短 | **急坂** | 通常 | ポケット(芝1600) |
| 中京 | 普通 | **急坂** | スパイラル | — |
| 京都 | 普通 | 平坦 | 通常 | — |
| 阪神 | 普通 | **急坂** | 通常/一部スパイラル※ | 坂発走(芝2000) |

※阪神の最終コーナー分類は読み取りに揺れあり(本文中スパイラル的挙動の記述)。コース辞典の半径で要確認。

**地形効果ルール(レース質への寄与):**
- **急坂**(中山/中京/阪神): 芝=先行有利 / ダート(乾燥期)=差し有利 / 芝ダ問わず**外枠不利**(距離・体力ロス大)。
- **スパイラルコーナー**(函館/福島/中京/小倉): 開催**前半=内枠先行(前残り)** / **後半=外枠差し(外差し)**。中京は急坂併発で「差し届かず」が出やすい。
- **直線長**(新潟外/東京): 芝=差し有利・枠の影響小 / ダート(東京)=上がりに限界で先行有利。
- **発走地形**: 下り発走→ハイペース / 上り発走→スロー / 最初のコーナーまで長→ハイ・短→スロー / ポケット発走→外枠不利。

### 2-5. ペース判別(ハイ/スロー)— 影響力順5要素

①でハイ/スローの当たりをつけ、残りで補正(影響力の大きい順):

1. **逃げ・先行馬の割合**(多→ハイ / 少→スロー)。差しでも好位追走から垂れる型は「先行馬扱い」。
2. **逃げ・先行馬の枠並び**(絶対逃げたい馬が 芝で外/ダで内 →ハイ)。
3. **馬場状態**(超高速・高速芝、稍重~不良ダート →ハイ)。
4. **発走地点地形**(前半下り/初角まで長 →ハイ)。
5. **騎手特徴**(先行型・減量騎手 →ハイ / 差し型・ベテラン →スロー)。

### 2-6. 風(風速5m以上で考慮)

直線の向きとの関係で脚質バイアスを補正:

| ケース | 条件 | 効果 |
|---|---|---|
| ① | 向正面追い風＋直線向かい風 | 先行有利(強) |
| ② | 向正面向かい風＋直線追い風 | 差し有利(強) |
| ③ | 3→4角 追い風 | やや先行有利 |
| ④ | 3→4角 向かい風 | やや差し有利 |

→ 各競馬場の直線方位は静的、当日風向はAPIで取得し `rq_wind_bias` を生成可能。

## 3. 馬キャラ = 馬レベル派生特徴量(履歴から計算可能)

本書最大のML資産。**過去走の通過順・上がり3F順位・ラップから機械的に判定できる**5タイプ+オプション。
各馬に「どの馬キャラか」のスコア/フラグを持たせ、レース質ラベルとの相性で買い候補が決まる。

| 馬キャラ | 判定条件(過去走から計算) | 得意レース質 |
|---|---|---|
| ①差して届かない | 向正面6番手以下(出走頭数の2/3以降) ∧ 4角通過順より最終着順が**4つ以上上昇** ∧ 上がり3Fメンバー**5位以内** | 芝ダ「差し・短縮・ハイ」/ 芝超高速「内・差し」/ 芝内荒れ「外・差し」/ ダ差し馬場「外・差し」 |
| ②伸びずバテず | 向正面3~10番手(中央1/3) ∧ 4角通過順比 最終着順**±3以内** ∧ 上がり3F中位(3~7位) | 芝ダ「内枠」/ 芝超高速「内・差し」/ 芝高速「内・先行」/ ダ先行馬場「外・先行」/ ダ雨馬場「先行・ハイ」 |
| ③逃げれば止まらない | 向正面**1~2番手**で追走 | 「逃げ」優位レース・単騎濃厚時。過剰人気リスク |
| ④平均ラップ得意 | 各ラップ差**±0.3秒以内**の好走経験 ∧ 道中8番手以内(前半1/2) ∧ 4角通過順比 着順±3以内 | 芝超高速「内・差し」/ 芝高速「内・先行」/ 芝荒れ「外・先行」 |
| ⑤追走力特化 | 高速馬場/ハイペースで好走経験 ∧ マクリ(向正面・3~4角、内マクリ除く)で好成績 ∧ 4角通過順比 着順が3位以内に**上げていない** | 芝「延長・ハイ」/ 芝高速「内・先行」/ ダ先行馬場「外・先行」/ ダ雨馬場「先行・ハイ」 |

**オプション馬キャラ(分類修飾):**
- **マクれる馬キャラ**: ②型(中団→3角入口で仕掛け直線先頭並ぶ・坂で再加速) / ①型(最後方→向正面~3角で一気・操縦性高)。距離延長・長距離で優位。
- **人気にならない馬キャラ**: 年齢/血統/主戦騎手で人気を落とす馬。適性比較が同程度なら優先(穴トッピング)。

> いずれも `通過順(1角/2角/3角/4角)`・`上がり3F順位`・`ラップ`・`着順` から計算可能 →
> JRDB/成績DBに揃う列で **馬キャラ確率ベクトル** を前計算し、レース質との内積を特徴量化。

## 4. KEIBA-CICD への接続(候補特徴量カタログ)

| 特徴量(案) | 生成元 | 必要データ | 種別 |
|---|---|---|---|
| `rq_frame` / `rq_style` / `rq_rotation` / `rq_pace` | §2ルールエンジン | 馬場状態・クッション値・含水率・メンバー脚質・コース定数・風 | レース単位ラベル |
| `course_const_*`(直線/急坂/コーナー/発走地形) | §2-4静的表 | 場・距離 | コース固定 |
| `cushion_bucket` / `cushion_course_adj` / `cushion_3d_ma` | §2-3 | JRA金曜発表値 | レース単位 |
| `moisture_bucket`(芝/ダ別) | §2-3 | 含水率 | レース単位 |
| `dirt_sashi_metric` = 逃げ上3F − 最速上3F | §2-2 | 当該レース過去傾向/当日前レース | レース単位 |
| `pace_score`(5要素加重) | §2-5 | 出走馬脚質構成・枠・騎手・地形 | レース単位 |
| `wind_bias` | §2-6 | コース方位 + 当日風向API | レース単位 |
| `umachara_prob[5]` 馬キャラ確率 | §3 | 過去走 通過順・上3F順位・ラップ・着順 | **馬単位** |
| `rq_match_score` = レース質ラベル × 馬属性一致度 | §1座標図 | 上記の積 | 馬×レース |

**既存資産との突合:**
- コース定数(§2-4)は `keibajo_course_constants.csv` で実数検証(直線m・高低差・1周)。
- 脚質/枠の事前バイアスは `keibajo_course_bias_long.csv` の `脚質別成績`/`枠番別成績` を事前確率に。
- 馬キャラ計算に要る通過順・上がり3Fは JRDB(`data3/jrdb`)に存在 → 列名は実装時に確認。

## 5. 実装メモ・注意

- **ラベルは段階的に**: まず①枠②脚質だけのレース質(全レース付与) → 効果検証 → ③④追加。
- **教師あり化**: 本書のレース質ラベルは「結果が出た後の答え合わせ」も定義(§0087: 上位入線馬の枠/脚質の偏り)。
  これは **過去レースに自動でレース質ラベルを付ける弱教師** として使える(着順上位3頭の枠・脚質・上3F順位の偏りから事後ラベル)。
- **OCR起因の要確認点**: クッション値の本文に表と矛盾する記述(「9.0以下=高速」)あり→**表(§2-3)を採用**。
  阪神の最終コーナー分類。馬場状態の時計閾値は1600m基準で距離換算が要る。
- **リーク注意**: 馬場状態・含水率・クッション値は前日~当日発表。`dirt_sashi_metric` は当日同条件先行レースから推定する設計にし、対象レース結果を使わない。
- **検証**: 生成した `rq_*` ラベルが コース辞典の脚質別回収値と方向一致するかでサニティチェック。

## 6. 次の一手

1. §2-4のコース定数表を `course_const_master.csv`(10場×距離×5属性)として固定化。
2. §3の馬キャラ判定を JRDB列にマッピングし、`umachara` 前計算バッチを試作。
3. 実践編(続巻)読了後、ラベル付けの具体手順・例外則を本仕様にマージ。
4. 「上がりXハロン」「双馬式 展開読み」読了後、§2-5ペース判別と上がり3F定義を統合(4冊横断 §別途)。
