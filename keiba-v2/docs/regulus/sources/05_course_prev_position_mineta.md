# 競馬場と前走位置取りだけで恒常的に勝つ方法 → ML特徴量 抽出仕様

> みねた『競馬場と前走位置取りだけで恒常的に勝つ方法』(2022)
> VLM読み取りノート(199枚=371p見開き)を Claude が ML特徴量設計に落とし込んだもの。
> 既存の [[横断統合_ML特徴量_展開×レース質×上がり×ノイズ除去]] を**実装容易な形で補強**する位置づけ。
> ⚠ 生サマリーにthinkリーク多(814)だが最終points/本specは綺麗。原文/画像は手元非公開、本データは型を消化した派生物。

## 0. なぜ重要か — 「前走通過順位」という実装容易プリミティブ

双馬式([[展開読み_ML特徴量]])は展開予測に**テン1F持ちタイム**(JRA非公表・入手難)を使った。
本書は同じ「展開(隊列・ペース)予測」を、**前走の3角通過順位**という**JRDBに必ずある公開データ**で代替する。
さらに全体を**期待値(予測回収率=勝率×オッズ)**の枠組みに載せる。→ **最も実装に近い1冊**。

核心3軸: ①コースパターン(初角まで距離) ②前走位置取り(先行馬割合) ③オッズの歪み(妙味)。

---

## 1. ★コア特徴量 — 前走通過順位 ≤3 =「先行意識の高い馬」

主観の「逃げ/先行」を捨て、**前走の道中通過順位が3番手以内**を客観的な先行プリミティブとする。
(1-1-1 / 2-2-3 等OK。自身が前走3番手以内であること)

| 特徴量 | 定義 | 種別 |
|---|---|---|
| `prev_corner_le3` | 前走3角(道中)通過順 ≤3 か | 馬 |
| **`front_ratio`** | レース内で `prev_corner_le3` の馬の**占有率** | レース |
| `prev_led_flag` | 前走3角通過 1番手(=前走逃げ) | 馬(妙味用) |

### front_ratio の閾値(ペース→有利脚質の予測)
| front_ratio | 想定ペース | 有利 | 実証値 |
|---|---|---|---|
| **<30%** | 緩む(上がりにくい) | **先行・内枠有利** | 先行馬割合30%未満×内枠 → **単勝回収率91.1%** |
| 30〜40% | 中間 | — | — |
| **>40%** | 上がる | **差し・距離延長馬有利**(同脚質ポジション争いで消耗) | 朝日杯FS 73%該当→差し決着 |
| 〜50% | (G1の標準) | ハイ寄り | G1は約50% |

→ これは [[レース質マトリックス_ML特徴量]] の `lead_side`/`rq_pace`、双馬式の `pace_scenario` を
**JRDBデータだけで生成**する実装。`front_ratio` が pace 予測の主役。

## 2. コースパターン(初角までの距離 + A〜F分類)

**初角までの距離**で内外有利が決まる(コーナーの外側距離ロス由来):

| 初角まで | バイアス |
|---|---|
| **300m未満** | 内枠先行 強有利(短距離・外枠先行に厳しい) |
| 300〜400m | 内枠先行有利 |
| **400m以上 / 500m以上** | 内外の有利不利 小。500m以上は先行争い長引きペースアップ |

例: 東京芝2000m=初角130m弱→外枠先行に致命的(天皇賞秋 8枠 0-0-2-22)。

**コースパターンA〜F**: 各競馬場×距離を巻末で A〜F に分類(初角まで距離・内外有利の型)＋**枠順別成績**(1〜8枠の勝率/連対/複勝/単複回収)を掲載(p230-267 + 巻末早見表)。
→ `course_pattern`(A〜F カテゴリ) と `course_frame_bias`(枠別回収) を辞書化。コース辞典([[project_keiba-course-dict]])・双馬式コース表と**3者突合**で精度↑。

| 特徴量 | 定義 |
|---|---|
| `dist_to_first_corner_m` / `first_corner_band`(<300/300-400/400-500/500+) | 連続+区分 |
| `course_pattern`(A〜F) | コース型 |
| `course_frame_bias[枠]` | 枠別回収値(辞書) |

---

## 3. 逃げハサミ(先行馬に挟まれる配置) — 枠並び特徴量

定義: ある馬(自身の前走通過順 >3)の**両隣の枠**が「先行意識の高い馬」(前走≤3)である配置。
→ その馬は発走で挟まれ位置を取りにくい/取りに行って消耗。出馬表確定時に枠並びから計算可能。

| 特徴量 | 定義 | 種別 |
|---|---|---|
| `escape_sandwich_flag` | 両隣が prev_corner_le3、自身は>3 | 馬×レース(枠並び) |
| `front_neighbors`(0/1/2) | 隣接枠の先行意識馬の数 | 馬×レース |

---

## 4. 妙味・オッズの歪み(EVモデル用) — 前走着順の心理バイアス

人気(オッズ)に織り込まれた**心理的歪み**を取りに行く。勝率モデルでなく**EV/妙味モデル**の特徴量。

| 特徴量 | 効果 | 実証 |
|---|---|---|
| `prev_led_flag`(前走逃げ) | **過剰人気=危険**(異級戦で甘い) | 前走逃げ馬 単勝回収**76%**/複勝74% |
| `prev_finish_ge10`(前走二桁着順) | **過小評価=妙味**(「一変ないだろう」心理で買い控え) | オッズ甘くなりEV取りやすい |
| `odds_distortion` = 実オッズ/予想オッズ | 歪みの大きさ | 5倍想定→実15倍で危険→美味 |

> [[上がりXハロン_ML特徴量]]§4(妙味の罠)・亀谷(人気ランク別ノイズ除去)と同系統。
> **「勝率用」と「EV/妙味用」で特徴量を分ける**設計をここでも徹底。

---

## 5. 期待値フレーム(モデル出力の使い方)

- **予測回収率 = 予測勝率 × 単勝オッズ ×100**。期待値=予測回収率/100。100%超(EV>1)だけ買う。
- 参考: 回収率100%超には「平均より**1.34倍**馬券が上手い」必要(母集団の難度)。
- 資金管理(実装外・運用層): 勝負レース ≤1%資本 / 非勝負 ≤0.1% / 月予算固定。

→ MLは `win_prob` と `ev = win_prob × odds` を出し、**EV閾値でベット選別**。買い目種(ワイド/3連複)は別ロジック。

## 6. 既存統合への接続(差分)

| 本書が足すもの | 接続先 |
|---|---|
| `front_ratio`(前走≤3占有率)で pace 予測 = **JRDB実装版** | 双馬式 `pace_scenario` / レース質 `rq_pace`・`lead_side` の**実装代替** |
| `first_corner_band` / `course_pattern`(A〜F) | レース質 `course_const_*`・双馬式 `dist_to_first_corner` を補完 |
| `escape_sandwich_flag` | 新規(枠並び×前走位置の交互作用) |
| `prev_led_flag`/`prev_finish_ge10`/`odds_distortion` | 上がりX妙味・亀谷ノイズ除去を**具体化** |
| EV=勝率×オッズ の選別 | 横断統合§出口(妙味モデル) |

**重要**: 双馬式の `tenF1`(入手難)が無くても、**`front_ratio`(前走通過順)で pace 予測を即実装できる**。
まずこちらで縦串(pace→レース質→脱交絡)を通し、テン入手後に `tenF1` で精度上乗せ、という順が現実的。

## 8. 注意・次の一手
- **リーク厳禁**: front_ratio・sandwich は確定枠順＋**前走**データで事前計算(対象レース結果不使用)。odds系は確定オッズ(直前)使用に注意。
- 数値(91.1%・76%等)はVLM目安＋2022年データ。**JRDBで再集計**前提。コースパターンA〜Fの正確な定義は巻末早見表を原本/データで確認。
- 非定常性([[レース質マトリックス_実践編_ML特徴量]]§4)同様、枠別回収は近年で再集計。
- **次**: `front_ratio` は前走通過順だけで作れる最短ピース → 双馬式の代わりにこれで `pace_scenario` を試作し、横断統合§4の最小縦串を回す。テン入手後に双馬式版へ格上げ。
