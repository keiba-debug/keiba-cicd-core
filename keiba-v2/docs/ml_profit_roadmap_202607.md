## 0. 前提 — 「精度向上」はもう主戦場ではない (実測済みの制約)

S165〜S183 の実測で確定している制約。**新アプローチは全てこの壁の上に設計する**。

| # | 確定事実 | 出典 |
|---|---|---|
| 制約1 | 単勝市場はほぼ完璧に較正済 (全オッズ帯 ±0.03) → **勝率精度で市場は出し抜けない** | edge_map §1.1 |
| 制約2 | モデルは favorite-longshot bias 持ち (強人気-0.19過小/人気薄+0.01過大=約3倍) → 幽霊点の根本原因。グローバル等調較正では直らない (単調=ランク不変) | edge_map §1.2 |
| 制約3 | 複勝は全帯で市場が過大評価 (ROI上限90.6%)、三連単 blanket も-EV → **点数・券種の工夫は控除率の壁を超えない** | edge_map §1.3-1.5 |
| 制約4 | 実在が検証されたエッジは **gap≥5単勝×(未勝利/条件/重賞) = ROI130% p=0.026** のみ。ただし高分散 (的中5%・連敗50-106) | edge_map §8 |
| 制約5 | danger(凡走)予測は単体では当たるが **W が吸収済みで増分ゼロ** (単勝市場が較正済のため金にならない) | edge_map §3 |
| 制約6 | 特徴量の増減では市場から離れられない (同じ材料を見ているから)。スタッキングは視点独立性を壊して逆効果 | edge_map §3 / [[feedback_no_stacking_across_stars_nebula]] |
| 制約7 | OP+ 上級クラスは情報天井 (Regulus B/B' 3連続NO-GO・JRDBが拾い切り)。**エッジは中情報クラス (未勝利141%/条件115%) に局在** | S183 / edge_map §2 |
| 制約8 | コメントAIの本物のエッジは複勝的中率+4.7pt (z=5.58) のみ。単勝ROIは尻尾依存で再現性なし | [[model-x-comment-narrowing]] |

**帰結**: 収益改善のレバーは「AUC を上げる」ではなく、
①モデル確率の**構造的な歪み(制約2)を直す**、②**市場が緩い場所(制約4/7)に専門火力を集中**する、
③検証済みエッジの**サイジングと選別を賢くする**、④**市場がまだ測られていない券種/セグメント**を測る、の4方向。

## 1. 現状の4モデルと収益接続 (2026-07-02時点)

| モデル | 対象 | 目的変数 | 版 | 収益への接続 |
|---|---|---|---|---|

## 2. アプローチ群A — 目的変数の再設計 (本丸)

「1着か否か」の精度勝負は制約1で詰み。**目的変数そのものを収益に近づける**。

### A-1. ★市場オフセット残差モデル (最優先候補)★
- **何**: LightGBM の `init_score` に市場確率のロジット `logit(p_market)` を入れて W を学習する。
  モデルは「勝つか」ではなく **「市場の値付けからのズレ」だけ**を学習する (offset modeling / residual learning)。
- **なぜ効くか**:
  - 出力が `市場確率 × 学習された補正` の形になり、**favorite-longshot bias (制約2) が構造的に消える**。
    断然馬を過小評価する現象は「市場情報を抜いたモデルが確率を散らす」のが原因で、土台を市場にすれば散らない。
  - gap 系エッジの本質は「モデルと市場の乖離が正しい場合」。残差モデルは**その乖離を直接目的変数化**したもの。
    gap≥5 シグナルの質 (的中5%→改善) に直結する。
  - 幽霊点 (ハーヴィル掛け算で人気薄が膨張) も土台側から解消 → 選定エンジン (S172) の器が使える確率が手に入る。
- **注意**:
  - 事前オッズの時点整合が生命線 ([[feedback_odds_gate_hindsight]])。学習に使う市場確率は「投票時点で見えるオッズ」限定。
    df_test 検証で事前=確定一致は確認済 (edge_map §7) だが、学習側パイプの oddsソースを明示的に固定する。
  - 「特徴量では市場から離れられない (制約6)」はこのモデルにも効く — 残差の大半はゼロになるはず。
    **成功条件は AUC でなく「gap picks の実払戻ROI が現行 gap≥5 (130%) を超えるか」**で判定する。
- **実装**: `experiment.py` に `--market-offset` モード追加 (init_score 注入 + 予測時 `sigmoid(logit(p_mkt)+raw)`)。
  既存 W と並走させ、gap 定義を「残差スコア上位」に置換した shadow 比較。
- **工数**: 中 (2-3セッション)。**期待収益インパクト: 最大**。

### A-2. ★メタラベリング — 「gap シグナルが当たるか」を予測する第二段モデル★
- **何**: 一次シグナル = 検証済 gap≥5 単勝。二次モデルの目的変数 = **「その gap pick が的中したか」** (binary)。
  特徴量 = レース文脈 (クラス/頭数/馬場/ペース想定/Eclipse の closing_proba/コメント信頼度/ARd等)。
  出力は「買う/見送る」ではなく**ベットサイズの重み** (Kelly 比率の調整) に使う。
- **なぜ効くか**: López de Prado のメタラベリングそのもの。エッジの発見 (済) とエッジの選別を分離する。
  S175 の教訓 (オッズ帯 best-of-search は過学習) に対し、**帯を手で選ぶ代わりにモデルに文脈で選ばせ、
  walk-forward でだけ評価する**のが正しい精密化。ROI130%・高分散 (CI下限81%) の分散低減が狙い。
- **注意**: 学習サンプルが少ない (gap picks は 13ヶ月で413件)。①backfill で picks 履歴を数年分生成、
  ②正則化強め+特徴量10個以下の極小モデル、③S175 の null 検定 (`ml/analyze/audit_gap_edge.py` 流用) を通すこと。
- **工数**: 小〜中。**「唯一の検証済エッジを太くする」ので費用対効果が高い**。

### A-3. 激走ラベル (sirius) — 妙味穴スリーブへの供給
- **何**: 目的変数 = `単勝オッズ≥10 × 3着内` (or 1着)。人気薄の好走パターン専用モデル。設計書あり ([[sirius-design]])。
- **収益接続**: [[tansho-central-strategy]] の「高ARD妙味穴 (20-100倍) 単勝」= 配当の天井供給源 ([[payout-ceiling-strategy]])。
  現行は ARd 頼み。専用ラベルで穴サイドの順位付けを鋭くする。
- **注意**: 制約2 (人気薄を3倍過大評価) はこのモデルでも出る。**評価は AUC 禁止・oddsband別の実払戻ROI一択**。
  scale_pos_weight で無理に釣り上げず、market-offset (A-1) との併用 (穴サイド残差) が本命形。
- **工数**: 中。基盤 (nova/) 整備済で着手可能。

### A-4. レースレベル「荒れ度」モデル — レース選定層の目的変数
- **何**: Eclipse と同じレース単位学習で、目的変数を **「荒れたか」** にする。候補ラベル:
  - `top3人気合計 ≥ k` / `三連単配当 ≥ 1万円` / `1番人気が3着外` の3種を並行検証。
- **なぜ効くか**: 選定エンジン (S172) の事前層 =「1日36Rを買いたい順に並べる」の指標がまだ無い。
  レース単位は馬単位より較正ノイズに頑健 (selection_engine §2)。**「エッジが出やすいレース」に予算を寄せる**のは
  馬単位の確率をいじらずに済む収益レバー。gap シグナル発生率×的中率のメタモデル (A-2) と融合可能。
- **既存資産**: Eclipse の47特徴量 (ペース圧/脚質多様性/RPCI/馬場) がほぼ流用可能。experiment_closing.py の骨格再利用。
- **工数**: 小 (Eclipse クローン+ラベル差し替え)。

### A-5. Plackett-Luce / conditional logit 化 (レース内正規化)
- **何**: 馬ごと独立二値ではなく、**レース内で確率が正しく総和1になる**構造 (softmax/PL) で学習する。
  三連単/馬連の組み合わせ確率もハーヴィル近似でなく PL から直接出せる。
- **位置づけ**: combo 市場にエッジ無し (制約3) が確定しているので**優先度は低い**。
  ただし選定エンジンで combo を「市場確率で組む」(edge_map §4) 際のモデル側セカンドオピニオン、
  および幽霊点の構造的抑制としては正攻法。A-1 が成功したら次に検討で十分。
- **工数**: 大 (パイプライン改造)。

### A-6. 過剰人気凡走ラベル (favorite betrayal) — 用途を限定して再利用
- danger-model は**単勝増分ゼロで棄却済 (制約5)** — 再挑戦しない。
- ただし棄却されたのは「W への増分」であって、**(a) レース選定 (荒れ度 A-4 の部品)、(b) 複勝/ワイド回避、
  (c) UI の「人気先行」バッジ** としての価値は未測定。A-4 の特徴量として `p_betrayal` を注入する形で回収する。
- 独立モデルとしての再開発は **非推奨**。

## 3. アプローチ群B — 確率構造・較正の修正

### B-1. 帯別(2次元)較正 — グローバル等調の限界を直す
- 現行: W はグローバル IsotonicRegression (ECE 0.003 に見えるが**帯別では崩壊** — 制約2)。
- 案: `(pred_w, 市場オッズ帯)` の2次元較正、またはオッズ帯別に等調を分けて学習。
  単調制約が帯間で外れるので、断然馬の過小評価と人気薄の過大評価を**別々に**補正できる。
- **A-1 (市場オフセット) が採用されれば不要になる**。A-1 の前哨戦/簡易版という位置づけ。工数: 小。

### B-2. モデル×市場のロジットブレンド
- `p_final = σ(α·logit(p_mkt) + (1-α)·logit(p_model))`、α をオッズ帯別に OOS チューニング。
- EV天秤の土台は市場確率 (edge_map §4 で決定済) なので、これは **combo・選定エンジン用の「歪んでない確率」**の供給手段。
  幽霊点キラーとしては最小工数。A-1 の劣化版だが1日で試せる。

### B-3. 評価ハーネスの目的変数を「収益」に統一
- 全実験の合否判定を AUC/Brier から **「実払戻ROI bootstrap CI + null 検定 (S175方式) + log-wealth」** に統一する。
  `audit_gap_edge.py` を汎用化して `ml/analyze/profit_eval.py` に昇格。
- これは「別の目的変数」の運用版 — **目的変数を変えなくても、選抜基準を収益にすれば開発の淘汰圧が変わる**。
  制約8 (単勝ROIの尻尾依存を見破った) の再現を仕組み化する。工数: 小。**全アプローチの前提インフラ**。

## 4. アプローチ群C — 市場の空白地帯を測る・攻める

### C-1. ★未実測市場の較正マップ拡張 (ワイド/馬連/馬単/枠連/三連複)★
- edge_map は単勝/複勝/三連単のみ。**ワイドは理論的に最も緩い市場の筆頭候補**
  (プール小・当たり組数可変で一般客の値付けが雑・コメントAIの複勝系エッジ (制約8) と相性良)。
- やること: calib_place.py と同じ手法で implied vs 実測、overround、帯別 imp/act を5券種分。
- **もしワイドに較正の緩みがあれば**: コメントAI複勝エッジ (+4.7pt) × ワイドが最初の新スリーブ候補。
  無ければ無いで「全券種効率的」を確定でき、単勝集中に完全な根拠が付く。工数: 小〜中。**情報価値が高い**。

### C-2. 障害市場の較正実測 + Enif のエッジ監査
- 障害はプール極小・参加者少・分析人口最少 = **市場が緩い可能性が構造的に最も高いセグメント**。
  Enif は既に買い目接続済みなのに、gap≥5 相当のエッジ監査 (S175方式) を一度もやっていない。
- やること: 障害版 df_test dump → 較正マップ → gap 系 backtest → null 検定。
  サンプル少 (年900R弱) なので CI は広い前提で、shadow 積み上げ優先。工数: 小。

### C-3. ★未勝利/条件クラス特化 specialist (nova 第2弾)★
- **エッジの実在地 (未勝利141%/条件115% — 制約4) に専門家を置く**。Regulus の教訓 (制約7: OP+は情報天井) の裏返し。
- 未勝利は「過去走1-3本しかない×市場も雑」= 特徴量の主役が変わる (調教・血統・新馬時内容・厩舎意図・馬体変化)。
  汎用 Polaris はここで平均化された重みしか持てない。幅広学習→適用絞りの原則 ([[feedback_train_scope_not_match_eval]]) に従い、
  **全クラス学習 + クラス特徴量 + sample_weight 増し** で作り、test は未勝利/条件に絞って gap ROI を比較。
- 成否判定: gap≥5×未勝利/条件の ROI/CI が Polaris 比で改善するか (B-3 ハーネス)。工数: 中。

### C-4. 新馬戦の非市場情報リサーチ (低優先・研究枠)
- 新馬 = 市場は最も非効率 (1人気 imp-act +0.121) だがモデルも盲目 (gap ROI 33.6%) — 制約4の裏面。
- 攻め筋は非市場情報のみ: 調教全丁データ、坂路ラップ、血統×厩舎の新馬勝率、セリ価格、兄弟初戦成績。
  edge_map §5-4 の位置づけ通り「取れない可能性大」— **時間をかけない。四半期に1回のスパイク調査扱い**。

### C-5. オッズ時系列 (締切前ドリフト) 特徴量
- mykeibadb にオッズ時系列があるなら「事前→確定の変化方向」を**予測する**モデル (最終オッズ予測) は、
  gap picks の「見かけの妙味が締切で消える」問題 ([[feedback_odds_gate_hindsight]] の実害) への防御になる。
- 用途は買い判断でなく**執行 (投票タイミング/見送り) の改善**。エッジ源ではない点に注意。工数: 中。

## 5. アプローチ群D — 意思決定層 (モデル外で収支を作る)

> エッジの素値 130%・的中5%・連敗50-106 (制約4) の世界では、**サイジングと選別が収支の半分**。

### D-1. メタラベリング連動 Kelly (A-2 の出口)
- 現行: gap 単勝スリーブは一律比率1%。A-2 の `P(pick的中|文脈)` で **分数ケリーを pick 別に変える**。
  deep fractional (≤0.3-0.5%/bet — S175 §8.3) を上限ガードにした上での傾斜。

### D-2. スリーブ・ポートフォリオ管理
- 本命EV単 × 逆張り gap単 (稼働中) に、妙味穴 (A-3)・ワイド系 (C-1次第)・障害 (C-2次第) を追加していく前提で、
  **スリーブ間の相関測定と資金配分** (相関低いスリーブの組み合わせが DD を下げる) を shadow ledger から定期算出。
  [[sleeve-orchestration]] のレジストリに `expected_roi / ci / correlation` メタを持たせる。

### D-3. レース選定層の実装 (A-4 の出口)
- 荒れ度/エッジ発生予測で 1日36R をランキング → 上位N に予算集中 (selection_engine §2 の事前層を埋める)。

### D-4. 撤退・縮小ルールの機械化
- 各スリーブに SPRT (逐次確率比検定) or CUSUM で「エッジ消失の早期検知」を付ける。
  forward CI が 100% を跨ぐ判定に2年かかる (S175 §8.4) 問題への対処 = 「勝ち確認」でなく**「死亡検知」を高速化**する発想。
  シズネ案件として設計レビュー推奨。

## 7. 優先順位と推奨ロードマップ

**評価軸**: 収支インパクト期待 × 実測済み事実との整合 × 工数。

### Phase 1 (次の2-3セッション) — 「検証済みエッジを太くする」

**A-1 市場オフセット残差モデル v0.1** (`experiment.py --market-offset`・S173同一split・--no-save):

  favorite-longshot bias (制約2) は狙い通り消滅。残るは 1.0-1.5倍帯 +0.13 (n=170・isotonic端の歪み)。

  PRIMARY R3 (ev≥1×rank≤3×3cls) = 80.0% CI[68,93] p_null=0.50 で null と区別つかず。

  → **それでも BestIter=1**。全ルール p_null 0.43-0.89 でエッジなし。
- **★A-1 最終判定★**: 現有の非市場特徴量144個には、どのレシピでも市場を超える残差情報が無い
  (制約1/6 の最強レベルの再確認・2レシピで再現)。よって:
  1. **A-1 はエッジ源ではない**。「歪みなし確率」は市場 implied をそのまま使えばよい
