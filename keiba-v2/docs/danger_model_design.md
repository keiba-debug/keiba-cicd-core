# 危険馬（凡走確率）モデル — 設計書 (Session 173・条件適性ミスマッチで「過剰人気の崩壊」を狙う)

> **対象**: 「実力はあるのに今回の条件で崩れる馬」を **市場と無関係に** 予測する凡走確率モデル。
> その結果その馬が人気なら「過剰人気の崩壊」= ◎割引 / 危険判定 / 3着付け / 妙味の源泉。
> **正本ステータス**: この doc が危険馬モデルの設計正本。初版 = Session 173 (2026-06-21)。
> **発端**: Polaris W モデルの importance 1位が `prev_race_popularity`（前走人気）という違和感
> → ablation で「特徴量いじりでは市場から離れられない」と実証 → 「市場が体系的に誤る所だけ狙う」へ。

## 0. 発端と原理（S173 議論の結論）

### 0.1 ablation が示した壁（S173）
W モデルの gain importance 1位が `prev_race_popularity`（12.23%、本実験構成で209,547=断トツ）。
ふくだの違和感「前走人気＝市場の意見の裏口」は診断として正しい。だが ablation（prev_race_popularity を
自前モデル W/P/AR から除外して再学習）の結果：

| 指標 | base(あり) | abl(なし) | 判定 |
|---|---|---|---|
| W AUC | 0.7989 | 0.7985 | ほぼ不変＝**冗長**（情報は avg_finish 等に入ってる） |
| Win VB gap≥5 単勝ROI | **102.8%** n=775 | **82.6%** n=1045 | **悪化**（候補は増えたが質が落ちた） |
| bet_engine aggressive/simple/standard/wide | 116/112/111/110% | 99/102/101/100% | **全悪化** |

→ **教訓**: 市場と同じ材料（過去着順・騎手…）を見てる限り、特徴量を抜いても市場から離れられない。
「市場とズレること」自体は目的でない（ズレを増やしたら悪化した）。S165(買い方)/S169(combo)/S173(特徴量)
の3方向から同じ結論 = **レバーは器でなく「市場が間違う所でモデルが正しいか」**。

### 0.2 出口は原理的に2つだけ
1. 市場が持ってない/軽視する**情報を足す**（非市場シグナル）。
2. 市場が**体系的に誤る既知パターンだけ狙い撃つ**（残差の符号が安定した部分）。

→ ②の中で符号が一番安定するのが **「過剰人気馬の崩壊」**。これが本モデル。

### 0.3 ふくだの2つの懸念と、それが導いた設計
- 懸念A「market_residual（着順−市場implied_prob）を学ぶには分析時に市場評価が要る」
  → 数式上 `E[着順−implied|X] = (is_winモデル) − (Xで市場を再現するモデル)`。X が市場と同じ材料なら
    後者が強力で **residual≒ノイズ**（ablation の壁の再来）。**全馬の市場残差は筋が悪い**と確定。
- 懸念B「過剰人気かどうかの判定にもオッズが要る／運用は直前に分析しなおす」
  → ★これが設計の核心★。オッズの使い方を2種に分ける:
    - ✗ **入力特徴量に入れる** = 市場ミミック化（避ける。現 `MARKET_FEATURES` で除外済）
    - ○ **条件・後処理に使う** = 市場を“標的”にする（リークでない・OK）
  → ふくだの整理「**条件悪化などの凡走確率モデルがあって、結果その馬が人気か見るのが筋**」が正解。
    予測は市場ゼロ、市場接触は買い目選定（直前）だけ。

## 1. 設計 — 2層 + 順序

```
層1【予測（分析）= 市場ゼロ・前日計算OK・直前に動かない】
  danger M(X): 「実力はあるのに今回の条件で崩れる」確率
    入力 = 条件適性ミスマッチ特徴量（オッズ非依存・確定値）
    ※ オッズを一切見ない → 直前にオッズが動いても予測はブレない
        │
        ▼
層2【買い目選定 = 直前オッズで照合・薄い・速い】
  danger 高い  ∩  市場が人気にしている  =  過剰人気の崩壊
    → ◎割引 / 危険マーク / 3着付け / その馬を外した買い目 / 相手の妙味
```

**順序が決定的**: 「人気馬を集めて崩壊を学ぶ」(入口で市場依存) ではなく、
「崩れる馬を市場と無関係に予測 → 結果人気か見る」(予測は市場ゼロ)。

現行アーキとも一致: `predict`（前日, danger計算）→ `vb_refresh`（直前オッズ, 照合）。

## 2. 特徴量 — 「○○苦手 × 今回その条件」（あえてシンプル・解釈可能に絞る）

ふくだ方針: 「内枠苦手・多頭数苦手・重馬場苦手など、よくある単純な条件の方が分かりやすい」。
= **馬個体の条件別適性（過去成績）が低い × 今回がその条件**。市場は前走着順・人気・総合力を強く見るが、
条件別の癖は粗くしか織り込まない → ここに乖離（特に人気馬ほど総合力で買われ見落とされる）。

### 2.1 既存特徴量で作れるもの（`ml/features/past_features.py`・全て bayesian 平滑化版あり）

| ふくだの「苦手」 | 既存特徴量 | 今回条件 |
|---|---|---|
| 重馬場苦手 | `heavy_track_top3_rate` | `track_condition` ≥ 稍重 |
| 多頭数苦手 | `field_size_category_top3_rate`(small≤11/mid≤15/large≥16) | `entry_count` の帯 |
| 距離不適 | `distance_fitness` / `exact_distance_top3_rate`(±100m) / `distance_direction_top3_rate` | `distance` / `distance_change` |
| 芝ダ替わり | `surface_switch_top3_rate` | `track_type` 替わり |
| コース苦手 | `venue_top3_rate` | `place_code` |
| 疲労 | `days_since_last_race` / `entry_count_change` | 中X週 |
| 血統不適(間接) | pedigree `sprint/sustained_top3_rate` | 距離区分 |
| 調教ダウン | `jrdb_cha_oikiri_idx` / `jrdb_cyb_*` | 前走比 |

→ **ふくだの挙げた苦手条件はほぼ既存特徴量で揃っている**（サンプル不足は平滑化で処理済）。

### 2.2 新規に作るもの
- **内枠別 top3率**（`waku_top3_rate` 仮）: 馬履歴に `umaban` あり → 過去の枠順別成績を計算可。
  今回の `wakuban` と突き合わせ「内枠苦手 × 今回内枠」。← S173 時点で**唯一の新規 feature**。
- 前走「楽逃げ」再現性（後回し）: 前走が単騎/楽ペースで好走 ∩ 今回逃げ馬複数。
  メンバー構成（レースレベル特徴量）が要るため第2弾。

## 3. 目的変数（target）— 市場非依存

「凡走」を**市場を使わず**定義する（人気なのに着外 で定義すると市場依存に逆戻り＝禁止）。

- **採用候補(a) 実績ベースラインからの下振れ**: その馬自身の過去走（着順/IDM/AR素能力/tbw）が示す
  期待水準に対し、今走が大きく着順/着差を落としたら underperform=1。「強いのに崩れた」を
  **馬自身の履歴だけ**で定義（市場ゼロ）。← 本命。
- (b) 我々の好走モデル(pred_p)上位なのに着外: 市場ゼロだが自己批判的で市場乖離を生みにくい。
- (c) 単純な着外: 弱い馬を拾い情報が薄い（却下寄り）。

> 目標変数の最終確定は §5 の単体lift検証の後（lift検証自体は単純な「人気上位の凡走」で先に回せる）。

## 4. 正直な懐疑点（採用前に潰す）

★ これらの条件適性特徴量は **既に W/P モデルに入っている**（FEATURE_COLS_VALUE 198本の中）。
なのに過剰人気◎の罠は残る。なぜ専用モデルが追加価値を持つか＝仮説:
- W は `is_win` の AUC 最適化 → 「得意条件の馬を**上げる**」方向に使い、「苦手条件の人気馬を**下げる**」
  ペナルティ方向は弱い（非対称・198本に希釈）。崩壊を target にした専用モデルはペナルティを鋭く学べる。
- 少数・解釈可能 → 印/割引の根拠として actionable。

→ **これは仮説。検証必須**: danger スコア（or 苦手フラグ）が既存 W の上に「人気馬の凡走」識別で
**lift を足すか**をデータで確認してから採用。足さないなら「198本に既にある情報の作り直し」= 不採用。

## 5. 検証計画（モデルを組む前に単体 lift から）

過学習回避（CLAUDE.md「小サンプル×多条件＝疑似科学」）のため、**まず1条件ずつ効き目を測る**。

### 5.1 単体 lift（第一歩）
- 母集団 = 人気上位（popularity ≤ 3 など）× test期間。
- 各条件で「苦手（条件top3率が低い・経験あり）」群 vs「not苦手」群に分け、**凡走率**
  （P(着外) / P(not top3) / P(負け)）を比較。lift = 凡走率(苦手) − 凡走率(not苦手)。
- 正で意味のある差 = その条件は過剰人気の崩壊を予測する。効くものだけ次段へ。
- **検証は予測時点/直前オッズで人気を定義**（確定オッズ定義は後知恵 [[feedback_odds_gate_hindsight]]）。

### 5.2 合成 → 軽量モデル
- 効いた苦手フラグを少数で合成（ロジスティック or 浅い GBM）。target = §3(a)。
- 評価 = ECE/AUC でなく「人気馬の崩壊識別 lift」＋下流の実払戻（その馬を外す/相手を買うROI）。

### 5.3 データソース
- `experiment.py --save-features` で test期間の結果付きスナップショット（features + finish + odds +
  popularity）を生成 → 単体lift スクリプトが集計。leak は split で制御（sire-cutoff 必須）。

## 9. ★S173 実測結論: danger-model は「収益モデルとしては不採用」★

設計後、実データ(df_test・13ヶ月OOS)で検証した結果:
1. **単体lift は当たる**: 人気馬の中で「コース苦手」着外率 +6.0%(z3.9)・「距離不適」+4.1%(z2.6)。崩壊の"予測"は可能。
2. **だが incremental-over-W で W が既に吸収済み**: pred_w を制御すると danger係数 ≈ 0(ロジ係数-0.008・p0.55)。W は苦手な人気馬を既に pred_w で割り引いてる(苦手 pred_w 0.156 vs 普通 0.216)。条件適性特徴量(venue/distance top3率)は元々W に入ってるため。
3. **収益性ゼロ**: 過大評価人気馬を消しても残り人気馬の単勝ROIは改善せず(win_ev全帯76-81%・控除率の壁)。単勝市場が較正済だから(→ [[market_calibration_edge_map]] §1.1)。

→ **danger は「予測できるが馬券エッジにならない」(市場効率)。収益モデルとしては不採用。** 印/エンタメの説明用途(「この人気馬は危険」)なら軽く残せるが本筋でない。
→ **発展**: エッジは「崩壊予測(危険馬)」でなく「過小評価の拾い上げ(gap≥5単勝)× 効くクラス(未勝利/条件/重賞)」にあると判明 → [[market_calibration_edge_map]] §2 へ。
